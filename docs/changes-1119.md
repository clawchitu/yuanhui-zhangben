## 全局
- 画布 375×812 → 390×844（iPhone 13）。正文 22、次要 18、标题 26、导航 22、同步状态 18；字号做成 `--f1/--f2/--fh` 变量，`body.std` = 标准模式。大按钮、价格、总价、主按钮、键盘、步进器两种模式都不变。
- 「黄记超市」→「元辉烟酒店」，App 名「元辉账本」。示例里去掉了全部香烟，换成饮料、酒、零食、日用品；整件码示例改为「可乐 1 箱 = 24 罐」。
- 「记账人 妈妈/爸爸/黄磊」全部去掉，流水显示手机名（柜台手机、爸爸的手机、小王（收银））。
- 新颜色：已过期 = 墨底白字；快过期沿用价签黄。红色仍然只表示卖出。
- 不需要小数点的数字键盘，「.」键留空（05、12a、15）。
- 商品小图：卖出价签左侧 64pt、登记页名称旁、商品列表行首，另外进货、盘点、快过期清单也带。没图的显示名字首字。所有图都是自己画的通用图或首字，不是真实包装。
- 出图改用 WebKit：`render.sh` → `tools/build.py`（把 css/js/iframe 内联）+ `tools/shot.swift`（WKWebView 截图）。不再依赖 Chrome 和本地端口。`render.sh 01-home.html` 可以只出一张。

## 要同步改 plan.md 的地方（这次只改了设计稿）
- `products` 表加图片字段：`image_key`（OSS 对象名，可空）、`image_source`（`barcode_api` / 空）。服务器在登记新商品查条码时下载图片，压缩后存 OSS；App 只从自己的服务器拿图；没有图的客户端用名字首字。收银员临时登记的商品可以没有图。第一版不做拍照换图。
