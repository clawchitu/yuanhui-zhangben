## 规则（plan-v2 S08、§12 Q2、§13 第 22 条）

- 条款**明确禁止**缓存 / 缩图 / 在自己的 App 里展示返回的图片 → 开关保持关闭，全部用首字。

- 演示店和 App Store 截图**无论如何**不用第三方图（服务器上演示店的商品不进图片任务，条码查询对演示店永远 `has_image=false`）。
