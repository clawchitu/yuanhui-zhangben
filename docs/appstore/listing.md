# App Store 商品页字段（S30）

填到 App Store Connect（下称 ASC）。语言：简体中文（主要语言）。字数用 `python3` 的 `len()` 数（一个汉字、一个标点各算 1）；括号里另给 UTF-8 字节数，ASC 如果按字节提示超长，以 ASC 为准。

规则（plan-v2 §10「内容」「备案与主体」）：App 名、副标题、描述、关键词里**不出现「烟」「酒」**；App 名、Bundle ID 与备案逐字一致；销售范围只选中国大陆。下面每个字段都已核对过不含「烟」「酒」。

分发方式：**Unlisted（不公开，凭链接下载）**，11/27 强哥定。商品页照样要填全（审核要看，拿到链接的人也会看到），只是不出现在搜索、分类和榜单里。申请草稿见 `unlisted-request.md`。

## 4. 描述

- 限制：4000 字符
- 实际：494 字符（1368 字节）
- 第一段按 §10 写清「门店自用，账号由门店开通」。「看看演示」那句的前提是服务器上 `demo_login_enabled` 已打开（11/26 负责人定：从第一次提审起就开，见 README「上架前还要人来做的事」）；如果提审时没开，删掉那一句。

```
元辉账本是门店自用的扫码记账工具，账号由门店开通，不开放注册；没有门店开通的账号无法登录使用。想先看看，可以在登录页点「看看演示」，进入一家用假数据的演示小店。

只记账，不收钱，不涉及任何支付。

【卖出】
顾客买东西，用手机摄像头或蓝牙扫码枪一扫，自动算总价；可以抹零、改总价。扫不出的码可以手输，也可以按商品名找。

【进货】
货送到了扫一下，填数量和进价就入库。整箱、整条的码按整箱算；需要管保质期的商品，进货时顺手记下到期日，快过期会提醒。

【记错了能撤】
卖错了、记错了，点「撤销」，可以撤整笔，也可以只撤其中一样。

【看账】
今天卖了多少、这个月赚了多少、店里货值多少、哪些快没货、哪些快过期，一页看清。赚了 = 卖出 − 进价，损耗单独列。

【家里几台手机一起用】
已登录的手机出一个码，家里人扫一下就能登录，不用输密码。收银员手机只能卖出，看不到进价和库存。没网时照常记账，连上网自动同步。

【字大好认】
默认大字模式，价格和按钮都做得大，长辈也看得清。

数据存放在中国大陆境内的服务器上。隐私政策：https://yuanhuishop.cn/privacy
```

描述里提到的功能要在提审的包里都能用。写这份时（11/27）「商品」（S25）、「盘点」（S26）在 App 里还是「这一页还在做」的占位页，描述里**没有**写这两项；它们做完后可以在「【看账】」后面补一段。

## 7. 分类

- **主要类别：商务（Business）**（建议）
- 次要类别：效率（Productivity）（建议），或不填

理由：这是门店的进销存记账工具，和「商务」最贴。不建议选「财务（Finance）」：财务类在中国大陆区会被问到金融相关资质，而这个 App 不涉及任何资金往来，选了只会多一轮解释。Unlisted 的 App 本来就不出现在分类列表里，分类只影响审核时怎么归类。
