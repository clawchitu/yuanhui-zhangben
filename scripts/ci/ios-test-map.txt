# iOS CI 选测规则：PR 改了哪些路径 → 在 PR 上跑哪些 UI 测试。
# 由 scripts/ci/ios-select-tests.sh 读；改了本文件，跑 scripts/ci/ios-select-tests.sh --self-test 看规则还对不对。
#
# PR 上一律跑：干净 checkout 编译 + 全部单元测试（YuanhuiZhangbenTests、ShopCoreTests）+ 下面的冒烟集 + 选出来的 UI 测试，
# 再跑 Release / Beta 构建检查（release-check.sh）。push 到 main 和每晚（北京时间 03:00）跑全量。
#
# 每行一条规则，字段用空格分开，# 开头是注释：
#   smoke <测试>                 冒烟集：PR 上不管改了什么都跑
#   full  <路径模式>             改到这些路径 → PR 上直接跑全量（公共层、导航、数据模型、契约）
#   ui    <路径模式> <测试>...   改到这些路径 → 加跑这些 UI 测试
#   none  <路径模式>             改到这些路径不加跑 UI 测试（单元测试、截图脚本、CI 自己等，冒烟集照跑）
# <测试> 写 UI 测试类名（S27UITests），或「类名/方法名」只跑一条。
# <路径模式> 相对仓库根，shell 通配：* 可以跨目录（ios/App/Features/Expiry/* 包括下面所有文件）。
#
# 一个文件按下面的规则逐条匹配：
#   1. 命中任何一条 full → 整个 PR 全量；
#   2. 否则收集它命中的所有 ui 规则的测试（可以命中好几条）；
#   3. 改了 ios/UITests/<类名>.swift 自己（且没命中 none）→ 自动加跑这个类（不用写规则）；文件名对不上类名（共用的辅助文件）→ 全量；
#   4. 上面都没命中、也没命中 none → 算「没登记的路径」，整个 PR 全量（宁可多跑）。
#      加了新的功能目录、新文件夹，在这里补一条 ui 规则，PR 才能只跑选测。
# 不在 ios/、contracts/、scripts/ci/ 下、也不是 .github/workflows/ios.yml 的文件（server/、docs/ 等）不参与选测。
# 改名 / 移动的文件新旧两个路径都算。
